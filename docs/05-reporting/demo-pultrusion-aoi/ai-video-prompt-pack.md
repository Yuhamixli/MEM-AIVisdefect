## 本轮改动对照

| 问题 | 处理 |
|------|------|
| 镜头1 侧向漂移、看不出滚筒输送 | Prompt 强制环心对齐 + 滚筒原位转、仅型材前进 |
| 镜头2 AI 内容单薄 | 与镜头3对调；改用更密的 `defect-hud` 首帧 + 多框/类别/置信度/缩略图 |
| 滚筒跟着物料跑；2/3顺序反 | 滚筒「原位自转或静止」；顺序改为 HUD → 产线HMI |
| NG 料太长、开盖、推杆变形 | 换短段 `reject` 首帧；禁止开盖；推杆伸出→入箱→收回，且保持刚性直线 |
