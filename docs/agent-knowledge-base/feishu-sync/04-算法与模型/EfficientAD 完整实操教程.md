2.EfficientAD模型
2.1优势
仅用合格品训练，不受缺陷不均衡影响，全盘拦截已知缺陷 + 未知新型缺陷，兜底开裂等高风险小样本不漏检；
2.2 价值
月产 31 万工件绝大多数直接放行，大幅削减下游分割算力压力。

2.4采集的原则
①分散采集，不要一次性拍完。
分 7~10 天、早中晚三班、所有 17 台拉挤机均匀取样，不要一天集中拍几百张。
②必须包含正常的工艺现象。
正常划痕、正常纹理、轻微反光、生产允许的细微纹路全部纳入 OK 训练集，模型才不会把正常工艺痕迹判成异常。
③三组 OK 图片严格不能重复。
训练、验证、测试的图片必须是不同工件拍摄，不能一份图片复制三份放入不同文件夹。
