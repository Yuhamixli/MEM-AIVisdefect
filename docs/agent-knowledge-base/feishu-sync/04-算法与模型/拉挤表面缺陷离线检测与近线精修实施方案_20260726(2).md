拉挤表面缺陷离线检测与近线精修实施方案_20260726(2)





复合材料拉挤制品表面缺陷离线检测与近线精修实施方案




申报单位：MEM-引导课AIVisdefect课题组（Group3）
编制日期：2026年7月26日

一、编制说明与适用范围
（一）编制目的
本方案依据课题任务书，并落实组内已决议的ADR-001（在线轻量、近线精修、离线飞轮分置）。本期把离线检测模块作为验收主战场，主检用YOLO族有监督模型；近线工具只服务难例精修和样本回灌。文中统一技术边界、接口口径和阶段计划，供详设评审和中期演示使用。
（二）适用范围
本方案适用于新能源汽车电芯压条用复合材料拉挤成型件的表面外观缺陷：离线识别、结构化结果输出、人工复核，以及近线精修工具的使用。系统输出是目检初筛辅助，不替代质量最终放行。
（三）不适用与本期不做
1）不把多层模型串成产线每帧唯一主路径，也不把异常筛查召回与监督检测召回相乘后当作验收口径。
2）不以产线PLC联动、在线节拍闭环作为本期硬交付。
3）色差增强、二值化只用于人工标注和复盘，不写入离线自动化主程序，不参与训练和推理。
二、总体目标与建设边界
（一）任务书硬目标（P0）
1. 图像采集方案（硬件选型与拍摄规范）。
2. 抽检不少于50件：检出不少于3类表面缺陷，查全率不低于80%，准确率不低于85%。
3. 缺陷定义卡、检测模型与离线检测模块（结构化输出）。
4. 第三方可独立操作的使用说明。
（二）内部建设目标
1. 离线模块在CPU上可跑通：放入图像后完成检测，并给出结构化结果和叠加图。
2. 近线精修能做难例定位、分割辅助和预标注回流，但不占用验收主路径。
3. 先做裂纹、气泡、划伤三类；其余四类随样本成熟再扩展。
（三）评价原则
选型与阶段验收按准确度、效率、成本三项论证。未实测的指标一律写待补，禁止编造。
三、总体架构
（一）架构原则
1. 验收主线尽量短：P0指标由离线YOLO检测模块直接承担。
2. 离线主检、近线精修、数据飞轮分开部署，禁止叠成一条串行唯一判决链。
3. 先把成像做稳再谈算法：光源和拍摄规范经试验后冻结；成像不定，指标无法复现。
（二）逻辑结构
离线主路径：原图入库后，做与训练一致的标准化预处理，由YOLO完成缺陷定位、类别判定和可选实例分割，写出result.json与overlay叠加图，供复核界面和批次追溯使用。
近线辅助路径：对低置信度样本，以及类别边界不清或形态少见的疑似缺陷，按需调用开放词汇定位、分割工具或多模态预标注；人工确认后进入训练集，用于更新离线模型版本。
可选增强：良品数据到位后，可并联EfficientAD等异常筛查，只输出异常摘要，方便补漏和找难例。异常分支不得删掉YOLO已检出结果，也不进入P0查全率分母的串行折算。
（三）与外部在线三层材料的关系
外部材料里常见异常粗筛、监督精检、大模型分析的分层写法，思路可以参考。本期落地收束为：离线YOLO主检，加近线工具精修。大模型和开放词汇模型放在异步旁路，用来提高标注效率，不打进离线模块依赖包，也不承担实时放行承诺。
四、离线检测模块设计
（一）模块定位
离线检测模块对应任务书中的软件载体：缺陷定义卡、检测模型、离线检测模块三者配套交付。要求可独立运行、可无网演示；第三方按使用说明能完成样例试操。
（二）主检测器
1. 基线模型：YOLO11-seg（实例分割权重可只出检测框；最终定版以选型关单为准）。
2. 运行环境：Python 3.10、Ultralytics、PyTorch；默认CPU，有GPU时再加速。
3. 输出内容：缺陷类别、像素坐标框、可选掩膜、置信度、模型版本、推理耗时和初判结论。
（三）缺陷类别
类别slug以课题缺陷图谱为准：裂纹crack、气泡bubble、缺纱missing_yarn、划伤scratch、异物foreign_matter、发白whitening、脏污contamination。本期演示和验收优先裂纹、气泡、划伤。
（四）命令行接口（要点）
提供detect命令，至少支持：输入路径、输出路径、模型权重、置信度阈值、设备、是否保存叠加图、配置文件、单图超时。配置项与命令行一一对应，命令行优先。退出码：0全部成功，1部分失败，2致命错误。
（五）结构化输出
每张图一份result.json，字段包括：schema版本、样件ID、批次ID、检测面、图像尺寸、模型版本、缺陷列表、汇总初判和复核状态。缺陷列表含缺陷编号、类别slug、中文名、包围框、置信度及可选掩膜。机器初判与人工复核分开记录；复核不得改写机器初判，以便做误报漏报分析和50件盲测。
（六）目录与交付包
输出按检测日期和样件ID落盘，保留图像副本、result.json与overlay。交付包含入口程序、默认配置、权重、样例图和接口说明，保证在无产线联机条件下也能演示完整流程。
（七）判定规则（初版）
无缺陷输出OK；检出已知类缺陷时默认REVIEW。拒收（NG）规则待允收标准与结构工程共签后再启用。输出仍是初步判断，不替代最终放行。
五、近线精修方案
（一）定位
近线精修用于复核、难例处理和数据生产，不进入离线模块运行依赖，不挡P0验收。
（二）能力分层
1. 开放词汇定位（如Grounding DINO）：少样本探查、新缺陷名试检、给分割提供提示框；达标后可退回工具位。
2. 难例分割（如SAM2）：框不准或不规则缺陷时补掩膜，方便讨论面积和严重度；按需调用，不是每张图都跑。
3. 多模态预标注（VLM）：加快标注和难例初标；入库前必须人工确认，建议抽检不低于10%。
（三）工作流
离线YOLO跑批后，把低置信度、易混类别、漏检争议样本送进近线队列。工具给出预标注或掩膜建议，由质检或标注员确认。数据集按7:2:1做版本升级；回归评测通过后，再把新权重发布到离线模块。
（四）禁则
1. 不得用近线模型顶替离线模块，充当第三方交付主程序。
2. 不得宣称大模型异步分析能够实时挡住漏检。
3. 未经人工确认的自动预标注，不得直接记入金标准。
六、数据、标注与评测
（一）数据管理
原图按版本入库；训练、验证、测试划分固定。评测按物理样件ID和批次拆分，避免同一件多面图像泄漏到训练与测试两侧，造成指标虚高。
（二）标注规范
包围框定义与YOLO导出口径一致（像素，原点左上）。类别名以缺陷图谱为准；旧名废弃时须留下映射记录。定义卡写清描述、典型图、允收和易混规则后，再扩类训练。
（三）评测口径
P0查全率、准确率只拿离线YOLO输出与金标准比对。近线工具和可选异常模型另报补漏率、标注耗时等内部指标，不并入任务书门槛做串行折算。50件过门禁还不足以证明量产能力，须报逐类指标，并在后续加大样本量。
七、预处理与成像协同
（一）自动化预处理原则
自动化程序只允许使用与训练一致的轻量预处理（如高斯降噪、CLAHE，须消融验证后再固化）。训练、验证、测试和推理参数必须一致。预处理在内存中完成，归档仍保留原图。
（二）人工辅助处理边界
色差增强、二值化不进自动化检测代码，不参与训练和推理；只用于标注放大、复盘和工程师排查。
（三）成像约束（协同采集方案）
曝光、增益、白平衡等自动调节应关闭或受控，减轻漂移带来的分数和置信度波动。多机位时固定几何关系。光源方案经试验设计后冻结，不得仅凭经验认定某一种打光而排除其他必要方案。
八、尺寸量化（增强项）
（一）目标
具备标定条件时，把掩膜或框的像素量换成毫米级参考值，供严重度讨论和台账使用。该项不是本期唯一验收条件。
（二）标定要点
各机位单独标定，禁止共用系数；标定板与工件成像平面保持一致；标定图严禁混入训练和异常建模数据。硬件改动后要复检，不得写成永久免维护。
（三）计算注意
斜视、非平面和景深变化会拉大等比例系数误差。写入报告时应标明为参考值，并写清适用条件。
九、系统接口与前后端衔接
（一）算法落盘
离线模块只在约定目录写入result.json、图像副本和叠加图。
（二）前端消费
由同步脚本把逐面结果转成检测展示用的jobs结构。算法侧和前端侧都不得绕过转换、私改对方格式。字段仍对齐：样件、批次、检测面、类别、框、置信度、模型版本、复核状态。
（三）权威文档
接口字段以仓库《离线检测模块接口设计方案》为准；需求字段对齐FR-D4。
十、分阶段实施计划
（一）详设阶段（至2026年7月30日）
冻结离线模块输入输出和结构化字段草案；锁定先三类定义卡骨架与样本计划；采集方案初稿齐套。
（二）中期阶段（至2026年8月15日）
完成离线模块MVP：样例图到结构化结果和叠加图；不少于三类可演示；50件测试方案就绪；使用说明大纲完成。
（三）完成阶段（至2026年9月15日）
离线模块封装交付；约定协议上三类指标达标且可复查；使用说明可供第三方试操；七类扩展进度如实说明。
（四）近线与增强并行（不挡主线）
主线稳定后，再逐步接入难例分割和预标注回流；良品库就绪后评估EfficientAD并联补漏。阈值和预处理以评测数据为准迭代。
十一、风险与管控
（一）主要风险
1. 成像未冻结，模型指标无法复现。
2. 样本不足，或按图而非按件划分，导致评测虚高。
3. 串行多层判决被写成防漏保证，形成错误安全预期。
4. 近线工具范围蔓延，挤占验收主线工期。
（二）管控措施
1. 先做光源与拍摄DOE，再扩大训练。
2. 评测协议写死：件级拆分、盲测冻结、逐类报告。
3. 对外表述分开写清本期离线交付和产线演进愿景；没有证据，不承诺品质事故不会发生。
4. 近线工作归入工具链和数据飞轮，单独排期，不替代GATE离线门禁。
