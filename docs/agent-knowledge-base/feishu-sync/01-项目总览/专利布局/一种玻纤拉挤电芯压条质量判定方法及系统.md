一、技术领域
本发明涉及工业机器视觉、复合材料产品质量检测及检测数据处理技术领域，具体涉及一种针对玻纤拉挤电芯压条多表面、多分段图像检测结果进行物理位置聚合，并依据质量规则所需证据的完整状态实施质量判定和补充检测的方法及系统。
二、与本发明最接近的现有技术
（一）现有技术方案概述
玻纤拉挤电芯压条属于细长连续型复合材料型材，通常需要检测上表面、下表面和两个侧表面。现有自动检测方案一般由工业相机、图像处理或缺陷识别模型以及结果管理软件组成：相机取得产品图像，模型输出缺陷区域、类别、置信度或尺寸信息，系统再依据预设阈值形成检出、未检出或者合格、不合格结果。
与本发明相关的公开方案主要涉及拉挤板材多光场检测、工业缺陷识别、监督模型与异常检测模型联合定位、多成像方式检测以及人工确认等方向。

（二）现有技术存在的客观问题
1. 多表面、多分段图像中的检测框不能直接代表产品上的唯一实际缺陷。同一缺陷可能同时出现在相邻图像中，或者被图像边界截断；若按单幅图像统计，容易重复计数、低估完整尺寸。
2. 二维视觉未检出或者视觉尺寸未超限，只能说明当前图像未形成明确的不合格证据，不能证明凸起高度、凹陷深度、表面粗糙度、擦拭后是否消失等其他必要条件已经完成检测并满足要求。
3. 当发现证据不足时，现有系统通常仅提示人工复核，难以准确确定需要补测的样件、表面和实际物理位置，补充检测结果也可能无法与原视觉缺陷稳定对应，无法形成完整闭环。
三、本发明要解决的技术问题
本发明要解决的技术问题是：针对玻纤拉挤电芯压条四表面、多分段检测产生的多个图像结果，确定其在实际产品上的物理位置并聚合为真实缺陷对象；针对每个真实缺陷，依据适用质量规则确定所需的视觉证据和补充检测证据；在证据不完整、图像无效或者异常尚不能定类时，对指定样件、指定表面和指定物理区间实施补充检测，并在必要证据完整后形成质量判定结果。
四、本发明的技术方案
（一）总体构思
本发明先将多表面、多分段和多模型输出转换到产品统一物理坐标，聚合形成具有唯一标识的物理缺陷事件；再根据质量规则建立该事件的证据需求集合，检查视觉证据和外部检测证据是否完整；对于缺失证据，按照物理缺陷事件的位置触发补拍、补测或消歧检测；最后按照明确不合格证据优先、证据不足进入待复核、证据完整方可合格的顺序输出结果。

（二）方法步骤
S1： 建立样件与图像身份关系。获取压条上表面、下表面、第一侧表面和第二侧表面的连续或分段图像，为每幅图像绑定样件标识、批次标识、表面标识、图像段标识、采集时间、图像哈希、采集配方和标定版本。
S2： 检查采集和标定有效性。检查必检表面和规定轴向范围是否覆盖完整，以及图像是否可读、清晰、曝光合理、无遮挡，标定关系是否与相机、镜头、采集配方和产品规格匹配。无效或缺失区域不作为“未检出缺陷”处理。
S3： 形成已知缺陷证据和未知异常证据。已知缺陷识别单元输出已定义缺陷的类别、区域和置信度；未知异常识别单元输出偏离合格纹理但尚不能可靠定类的异常区域和异常分数。两路结果分别保留，未知异常不得强制转换为已知缺陷类别。
S4： 构建物理缺陷事件。依据相机标定、编码器位置或图像段起始位置，将候选区域从像素坐标转换为表面编号、轴向毫米位置和面内位置；当同一样件、同一表面的多个候选区域在物理位置上重叠或接近，且类别或形态相容时，将其聚合为具有唯一事件标识的物理缺陷事件，同时保留全部来源图像和原始模型结果。
S5： 执行物理规则和建立证据需求。系统以物理缺陷事件为对象测量长度、宽度、面积和位置，并在产品轴向毫米坐标上执行规定长度内数量、相邻间距和禁入区域等规则；同时依据缺陷类别和适用质量条款，确定本次判定所需的视觉证据、外部检测证据和消歧证据。
S6： 判断证据完整性。对每项必要证据记录其类型、取得方式、测量值、有效状态和对应物理缺陷事件。视觉尺寸未超限但高度、粗糙度或擦拭结果尚未取得时，系统将相应证据标记为缺失，不得直接输出合格。
S7： 实施定点补充检测。根据物理缺陷事件的样件标识、表面和物理坐标以及缺失证据类型，生成补充检测指令；所述指令用于控制或指示输送定位机构、相机、光源、位移传感器、轮廓仪或其他检测装置，对指定物理区间实施复拍、切换光照、擦拭后复拍、高度测量或其他检测，并将补充结果关联至原物理缺陷事件。

S8： 输出质量状态。存在有效且足以证明某项质量规则不满足的证据时输出NG；不存在明确NG证据，但存在图像无效、检测范围缺失、必要证据缺失、未知异常、类别冲突或规则冲突时输出REVIEW；只有全部必检范围有效、全部必要证据完整且不存在不合格项和待处理异常时，方可输出OK。

S9： 固化机器结果并追加复核记录。机器结果保存原图哈希、物理缺陷事件、模型版本、规则版本、标定版本、证据快照和机器结论；人工复核、补充测量或后续复算以新增记录方式引用原机器结果，不覆盖机器当时的原始判断。

五、典型实施方式（没实施）
实施例一：跨图像边界缺陷的聚合和统计
在一种实施方式中，同一表面由沿轴向排列的多个图像段构成，相邻图像段具有重叠区域；在另一种实施方式中，线阵相机形成连续长图后由软件划分为多个处理区段。若两个候选区域属于同一样件和同一表面，并且转换后的物理区域重叠程度达到阈值或者物理中心距离小于阈值，同时类别或形态相容，则将其聚合为一个物理缺陷事件。聚合后的事件只参与一次数量统计，其尺寸由多个来源区域的物理并集或融合轮廓确定。

若某一必检表面存在漏拍、失焦、过曝、遮挡或标定失效区间，系统将该区间标记为无效，并生成包含样件标识、表面、轴向起止位置和失败原因的补拍指令。即使其他区域均未检出缺陷，系统仍输出REVIEW；只有补拍后检测范围完整且图像有效，才继续执行质量规则。
六、技术效果
1.发明将不同表面、不同图像段及不同检测模型输出的候选区域转换至产品统一物理坐标，并对属于同一实际缺陷的候选区域进行关联聚合，能够减少重叠区域中的重复计数，并恢复跨图像边界缺陷的完整尺寸。该效果可通过重复计数率、缺陷尺寸重构误差及缺陷合并准确率进行量化评价。
2.本发明以具有唯一标识的物理缺陷事件作为尺寸测量、数量统计、间距计算、补充检测和复核处置的共同对象，使规定物理长度内的缺陷数量、间距和分布规则能够跨越单幅图像边界执行，从而提高连续型材质量统计结果的一致性。
3.本发明根据质量规则建立视觉证据、外部测量证据和消歧证据之间的对应关系，能够区分“当前尚未发现不合格证据”与“质量规则要求的全部必要证据已经取得”，避免仅依据二维视觉未检出或者视觉尺寸未超限而形成无充分依据的合格结论。
4.本发明根据物理缺陷事件的样件标识、表面标识和物理坐标，生成与缺失证据类型相对应的补拍或补测任务，使补充检测装置能够针对指定物理区域取得检测数据，并将补充检测结果回填至原物理缺陷事件，从而缩短缺陷重新定位时间，减少补测对象错配。
5.在图像漏拍、失焦、过曝、标定失效、未知异常、证据缺失或者证据冲突的情况下，本发明阻止系统直接输出自动合格结果，并给出相应的补拍、补测或复核动作，从而降低检测链路异常和必要证据缺失造成的错误放行风险。
6.本发明将原始图像、候选区域、物理缺陷事件、检测证据、模型版本、规则版本和标定版本与每次机器判定关联保存，人工复核和补充检测采用新增记录方式写入，使机器原始结果和后续处置过程能够被还原和比较，提高检测结果的可复现性与可追溯性。
七、可替代实施方式
已知缺陷识别可采用目标检测、实例分割、语义分割或传统纹理算法；未知异常识别可采用基于特征距离、记忆库、重建误差、教师—学生网络或其他异常检测方法。具体模型类型不构成本发明的限制。
产品物理坐标可通过相机标定、编码器位移、运动平台位置、图像段起点、基准标记或上述方式的组合建立；物理缺陷事件的关联可采用物理区域重叠、中心距离、轮廓连续性、方向相似度、类别相容关系或上述条件的组合。
补充检测可以采用原配方复拍、不同光照或偏振条件复拍、擦拭前后复拍、激光位移、轮廓测量、结构光测量、粗糙度测量或者其他能够取得相应技术参数的检测方式。规则可通过配置文件、数据库、决策表或规则引擎实现。
八、关键技术点及建议保护重点
本发明的核心是：先把不同图像和不同模型识别到的结果归并为产品上的同一个真实缺陷，再根据该缺陷尚缺少的检测证据，对其实际位置进行补拍或补测，证据齐全后再形成质量结论,形成闭环处理。
建议独立权利要求围绕上述最小闭环撰写，依次限定物理坐标转换、同一缺陷聚合、证据需求判断、定点补测、结果回填和质量判定；具体模型名称、固定阈值、特定传感器、版本管理和人工复核记录放入从属权利要求。这样既保留能够支撑创造性的必要技术特征，又避免独立权利要求因限定过细而使保护范围过小；从属权利要求再逐层增加四表面、多分段、未知异常、物理长度窗口、三态门控和追加式记录。
