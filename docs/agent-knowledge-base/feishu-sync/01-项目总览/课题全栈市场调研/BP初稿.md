一、行业趋势
1、行业快速发展
产业战略定位：国家新材料产业重点布局，新质生产力的核心支撑
下游需求爆发：新能源汽车 + 风电叶片 + 建筑行业
国产替代加速：碳纤维、高性能树脂自给率提升，成本持续下降

2、行业面临挑战
量的跃升：产线加速、产能扩大，待检产品指数级增长
质的跃升：从建材/日用品→风电/航空航天/新能源汽车，质量要求日益提升
可持续发展：知识无法沉淀 + 组织能力无法迭代
二、传统PDCA无法应对挑战
P（计划）：生产主管或资深技工凭经验制定质量标准，一经设定长期沿用
D（执行）：工人按固定SOP操作，工艺参数按固定值设定
C（检查）：人眼目视+手触摸，结果记录于台账
A（处理）：重大质量问题开会讨论，修订后重新下发SOP
缺陷一：效率低 ⇄ 与“量的跃升”不匹配
人工检查无法匹配高速产线
产能扩张需等比增加人力，而劳动力供给持续萎缩（年轻人不愿意干）
缺陷二：可靠性不足 ⇄ 与“质的跃升”不匹配
主观性强，判定结果因人而异
疲劳导致判定波动
缺陷三：知识无法沉淀 ⇄ 与“可持续发展”不匹配
隐性知识存于个人脑中，无法转化为组织资产
资深员工离职即带走经验，新员工从零积累
数据非结构化存档，无法溯因分析
三、智能化PDCA可以应对挑战
P（计划）：基于缺陷数据库自动识别规律，动态生成质量标准与排产建议
D（执行）：产线看板实时显示质量评分，异常即时预警，边干边改
C（检查）：100%在线全检，实时输出缺陷类型/位置/等级
A（处理）：缺陷与工艺参数关联分析，输出溯因报告，自动同步至P

四、智能化PDCA从C切入
1. C是智能化PDCA的前提
所有下游整改和优化都源于检测结果
C的结构化数据是A溯因分析、P排产优化、D实时反馈的前提
没有C的数据，P、D、A无法运转
2. C环节独立性最强，实施风险最低
以“附加单元”形式接入现有产线
不需改动现有设备与工艺流程，不影响正常生产
上线即见效，是全局智能化转型的“先导验证项目”
3. AI技术对C环节的替代最为彻底
C环节所有检测任务（表面缺陷/尺寸精度/内部结构/材料一致性）均属“数据采集→特征提取→模式识别→判定输出”类型
与AI技术高度契合，最接近端到端自动化
五、C从机器视觉表面缺陷检测切入
表面缺陷是最易发现的问题——最直观、最易被客户识别和投诉，验收门槛最低
机器视觉技术针对性强、成熟度最高——深度学习在图像识别任务上已超人类水平，产业链高度成熟
部署风险最低——无需大改产线
数据基础可复用——为后续扩展至内部结构检测、尺寸检测等奠定基础
六、机器视觉检测方案：软硬件部署
软件
改进型YOLO11-seg目标检测 + 异常检测分支（EfficientAD）
已知缺陷识别（裂纹/气泡/划伤）+ 未知异常提示（触发REVIEW）
规则层聚合判定（尺寸/数量/PTS条款 → OK/NG/REVIEW）

硬件
高分辨率工业面阵相机 × 4（顶/右/左/底）+ 定焦镜头
定制光学方案（条形光源、可调角度、偏振可选）
四段滚筒输送 + 气动分拣（OK直行/NG侧推/HOLD隔离）
PLC顺序控制 + 光电触发 + 安全联锁

部署
非接触式检查线，适配产线节拍
Windows本地离线运行，断网不影响主流程
对接MES预留接口，检测数据自动结构化存储
交钥匙式交付：需求调研→数据采集→模型训练→部署联调→培训交付
实施周期：约6个月
七、横向做宽：从单点标杆到全行业覆盖
V公司内部全面铺开
同子行业同类公司（宁德体系+比亚迪体系供应商）

八、纵向延伸：从C到P-D-A全链条打通
C→A：缺陷数据+工艺参数关联分析，输出溯因分析报告
A→P：溯因分析规律反馈至计划环节，动态优化质量标准
P→D：优化后标准下发产线，实时反馈即时干预
完整闭环：检测→根因分析→计划优化→执行校准→再检测
