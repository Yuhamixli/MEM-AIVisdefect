任务书_基于机器视觉的复合材料拉挤制品表面缺陷检测（郭小川）
基于机器视觉的复合材料拉挤制品表面缺陷检测
课题背景
本课题以新能源汽车电芯压条用复合材料拉挤成型产线为对象。当前拉挤件表面缺陷（裂纹、气泡、缺纱、划伤、异物、发白、脏污等七种）完全依赖人工目视检验，效率低、一致性差，且无法形成结构化数据支撑SPC统计过程控制和批次追溯。结合产线现有APQP控制计划与特性清单，外观特性尚未纳入自动化检测体系，是产线质量管理中的薄弱环节。为实现对产品表面缺陷的自动化识别，课题将采用图像采集手段获取拉挤制品表面信息，并基于机器视觉算法进行缺陷分析，替代人工目检的初步判断。
目标成果
设计图像采集方案（硬件选型、拍摄规范）;
建立缺陷定义卡（含描述、示例、特征、允收标准），训练缺陷检测模型；封装离线检测模块输出结构化结果;
编写第三方可独立操作的使用说明文档，支撑第三方独立操作。
考核指标
一份交付采集方案； 
抽取50件产品参与测试，可识别不少于三类表面缺陷，缺陷查全率≥80%，准确率≥85%；
一份使用说明文档。
