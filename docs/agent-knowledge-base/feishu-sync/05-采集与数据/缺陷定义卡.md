二、缺陷定义明细
D01 裂纹（Crack）


项目

内容

依据或影像说明

缺陷名称

裂纹

Crack / D01

来源/依据

PTS未直接列明；PTS#22要求CNC加工后白线无开裂；ASTM D4385-19 Crack；GB/T 3961-2009、GB/T 31539-2015

ASTM D4385将深入一层增强材料或约0.5mm的可见分离定义为裂纹，并判为不可接受；本卡采用从严原则

定义描述

制品表面出现连续或间断的线状开裂、分离或尖细暗线/亮线，可能从表层进入树脂基体或纤维增强层。

常见形态为细长、端部尖、走向不完全规则；暗场下常呈高亮线。

允许条件

无可见结构性裂纹。仅当白线/细纹无触感、无开口、无露纤、无分层且可归入发白/合模线/工艺白线时，按对应缺陷条款复判。

对安全和承力有潜在影响，算法应优先召回。

不允许条件

任何可见开裂、贯穿性开口、伴随翘边/分层/露纤的线状缺陷；深度达到或疑似达到一层增强层、约0.5mm及以上时直接NG。

NG后隔离并进行人工复判/必要时截面确认。

易混淆缺陷及区分方法

区别于划伤：划伤多为外力摩擦形成，边界较直，可仅伤及表层；裂纹有开口感、端部尖细或伴随暗场高亮。
区别于发白：发白是颜色变化，无开裂或台阶。

可用斜光/暗场、触感、显微放大和截面复检区分。

检测算法建议

线特征增强 + 暗场图像；Canny/Frangi/Top-hat与深度学习分割结合；设置高召回阈值并输出骨架长度、宽度和置信度。

裂纹误漏风险高，宁可多报后复判。

OK样图：表面光滑连续，无线性开口、无尖细暗纹，纹理均匀。

[图D01-02 NG]

视场50×40mm；同轴明场照明；倍率5×；24MP彩色相机。

NG样图：表面可见长约8mm、宽约0.08mm深色细长线，端部尖细，红色虚线圈出并标注L、W。

[图D01-03 NG-暗场]

D02 气泡（Bubble）


项目

内容

依据或影像说明

缺陷名称

气泡

Bubble / Blister / D02

来源/依据

PTS#9气泡；ASTM D4385-19 Blister

PTS为一级判据；ASTM用于统一气泡/鼓包的描述。

定义描述

表面或近表层出现圆形、椭圆形鼓起、透明/半透明斑或内部空腔，通常由树脂包气、挥发物或层间局部分离造成。

视觉上可表现为亮斑、阴影环、局部凸起或小点状泡。

允许条件

按PTS#9：气泡L≤10mm、W≤8mm、H≤0.25mm，且100mm距离内N≤5个允许；密集型/离散型小气泡D≤5mm、H≤0.5mm、表面能≥25dyn/cm允许。

需同时满足尺寸、数量、高度和表面能要求。

不允许条件

任一尺寸/数量/高度超过PTS#9；气泡破裂、开口、露纤、伴随分层；位于粘接/装配/绝缘关键区域且影响功能时NG。

关键区域即使尺寸较小也建议复判。

易混淆缺陷及区分方法

区别于异物：气泡通常有环状高光或凸起阴影，异物颜色/材质与基体不同。
区别于凹痕：气泡为凸起或内部空腔，凹痕为下陷。

侧光/同轴光组合可区分凸起与颜色差。

检测算法建议

明场检测圆斑 + 侧光凸起特征；连通域分割、Blob检测、实例分割；按100mm滑窗统计数量。

小气泡需与纹理噪声分开训练。

OK样图：表面平整，无闭合圆斑或凸起阴影。

[图D02-02 OK-限度]

视场100×40mm；明场+侧光；标尺1mm。

限度样图：单个气泡L≤10mm、W≤8mm、H≤0.25mm，100mm内N≤5，标注尺寸和数量。

D03 缺纱（Missing Yarn）


项目

内容

依据或影像说明

缺陷名称

缺纱

Missing Yarn / Dry Fiber / D03

来源/依据

PTS未直接定义；参考PTS#8缺毡；ASTM D4385-19 Dry Fiber、Exposed Reinforcement、Fiber Blooming；GB/T 31539-2015

将缺纱定义为纱束/表面毡/增强纤维局部缺失、断裂、外露或未被树脂充分浸润。

定义描述

拉挤件表层或边缘出现纱束缺失、纤维断丝、未浸润干纤维、露纤、局部无毡/无纱区域，导致纹理空缺、毛糙或增强层可见。

对承力、绝缘、耐久和后续粘接有风险。

允许条件

仅当缺陷可归入PTS#8缺毡限度：每500mm长度缝编毡跑偏N≤1处，且无毡区域宽度W＜1/3压条宽度；同时无干纤维、无露基材、无纱束断裂、无分层。

该项为PTS未定义缺陷的保守类比判据。

不允许条件

出现干纤维、露纤、纱束断裂或增强层缺失；无毡/缺纱宽度W≥1/3压条宽度；每500mm内N>1；伴随毛刺、分层、开裂、缺料或影响装配/粘接。

结构性或耐久性风险，直接NG并隔离。

易混淆缺陷及区分方法

区别于发白：缺纱可见纤维纹理空缺/毛糙/台阶或露纤，发白通常仅颜色变化。
区别于划伤：划伤有外力方向性沟痕，缺纱多沿纤维方向或边缘呈连续缺失。

用斜光观察表面高度，用放大图确认纤维是否完整。

检测算法建议

纹理异常检测 + 方向滤波；使用高分辨率明场/斜光图，训练分割模型识别纤维断裂、露纤和无毡边界。

建议与发白、划伤建立互斥标签。

OK样图：纤维/毡纹理连续，表层树脂覆盖完整。

D04 划伤（Scratch）


项目

内容

依据或影像说明

缺陷名称

划伤

Scratch / Scuff / Gouge / D04

来源/依据

PTS#15钢片划伤；ASTM D4385-19 Chips/Gouges、Scuffing；GB/T 1446-2005

钢片划伤按PTS；复材基材表面划伤按ASTM补充判定。

定义描述

外力摩擦、拖拽、碰擦或尖锐物接触造成的线状擦痕、沟痕或材料去除，可能仅影响表面光泽，也可能穿透表层露出基材/纤维。

视觉上通常方向性强，边界较直或呈擦拭带。

允许条件

钢片/T衬套区域按PTS#15：长度L和宽度W不管控，但划伤处绝缘层不漏基材，且绝缘耐压符合要求。复材表面仅允许轻微擦痕：无露纤/露基材、无开裂、未穿透表面毡、无明显台阶。

若有材料去除，参照ASTM chips/gouges限度并从严复判。

不允许条件

露基材、露纤、绝缘层破损或耐压不合格；穿透表面毡；伴随裂纹/开裂/分层；沟槽有明显深度、锐边或影响粘接/装配外观。

基材划伤无PTS直接限度，功能风险优先。

易混淆缺陷及区分方法

区别于裂纹：划伤多为外力方向性沟痕，端部钝化；裂纹端部尖细且可有开口。区别于脏污：划伤不可擦除，脏污可清洁去除。

清洁复检可排除脏污；暗场可强化沟槽边缘。

检测算法建议

方向滤波 + 细线分割；明场识别颜色变化，暗场/斜光识别沟槽边缘；输出与裂纹的二级分类置信度。

对露纤/露基材划伤设置NG强规则。

D05 异物（Foreign Object）


项目

内容

依据或影像说明

缺陷名称

异物

Foreign Object / Inclusion / D05

来源/依据

PTS#2杂质/黑点；ASTM D4385-19 Black Marking可作不可清除黑印参考

本卡将嵌入、粘附且不可按清洁方式去除的非本体材料归为异物。

定义描述

表面或近表层存在与基体不同颜色、质感或反光特征的颗粒、黑点、杂质、夹杂物、残留物或嵌入物。

若可擦除，应优先归为脏污并清洁复检。

允许条件

按PTS#2：单根产品杂质数量N≤10，单个杂质直径D≤8mm允许；黑点允许。异物不得松动、凸出、刮手或影响装配/粘接/绝缘。

黑点需确认非烧伤、非裂纹、非污染扩散。

不允许条件

单根产品N>10或单个D>8mm；异物松动、凸起、硬质、尖锐、脱落风险；影响外观功能、装配、粘接、绝缘或客户识别码读取。

若性质不明，按NG隔离复判。

易混淆缺陷及区分方法

区别于脏污：异物不可擦除或已嵌入。区别于气泡：异物无闭合鼓包环和高度渐变。
区别于烧边/烧伤：烧伤伴颜色扩散或热损伤。

清洁前后图像对比是关键。

检测算法建议

颜色/亮度异常检测 + Blob检测；清洁前后差分；对黑点、杂质分别建类并统计D、N。

浅色背景下黑点较易检测，深色异物需多光源。

D06 发白（Whitening）


项目

内容

依据或影像说明

缺陷名称

发白

Whitening / White Line / D06

来源/依据

PTS#11发白；PTS#22 CNC加工后白线；GB/T 3961-2009术语参考

PTS直接给出宽度和触感/开裂限制。

定义描述

制品表面出现条状、线状或片状灰白/乳白色区域，通常由表面毡外纱、应力白化、CNC加工、树脂/纤维界面微损伤或光散射造成。

本类不包含已经开裂、露纤或有台阶的缺陷。

允许条件

按PTS#11：单根产品条状发白长度不限，但宽度W≤3mm；由工艺优化（毡外纱）引起的贯穿性偏灰白线允许，表面触摸无台阶面。按PTS#22：CNC后白线无明显触感、无开裂允许。

需确认无裂纹、无露纤、无分层。

不允许条件

条状发白W>3mm；有明显触感/台阶；伴随开裂、露纤、起皮、凹坑超限、分层或影响外观一致性。

开裂时优先归入裂纹并NG。

易混淆缺陷及区分方法

区别于裂纹：发白无开口、无尖细裂纹边界。
区别于缺纱：发白表面纤维连续且无毛糙/露纤。
区别于划伤：发白无明显沟槽方向性。

触感、暗场和放大图可确认是否开裂。

检测算法建议

颜色空间阈值 + 纹理连续性判断；白线分割后测W；对W>3mm或伴随裂纹特征自动NG。

需用OK工艺白线样本训练，降低误报。

D07 脏污（Contamination）


项目

内容

依据或影像说明

缺陷名称

脏污

Contamination / Dirt / D07

来源/依据

PTS#16脏污；PTS附表1外观检查环境

PTS明确：表面可擦拭脏污、灰尘不允许。

定义描述

制品表面附着的可擦除灰尘、油污、手印、粉末、胶印、包装污染或其他外来污染物，不属于材料本体。

清洁后消失的归为脏污；清洁后仍存在的转异物/色差/发白复判。

允许条件

来料/成品判定时不允许可见可擦拭脏污。若制程内发现，经规定清洁后无残留、无划伤、无异物，可记录为已清洁OK。

对机器视觉训练应保留“清洁前NG/清洁后OK”成对样本。

不允许条件

任意可见灰尘、油污、手印、胶印、粉末等可擦拭污染；清洁后仍有痕迹或影响粘接、喷码、二维码读取、外观一致性。

清洁不能造成二次划伤。

易混淆缺陷及区分方法

区别于异物：脏污可擦除，异物嵌入或不可擦除。
区别于划伤：划伤清洁后仍有沟痕。
区别于黑点：黑点不可擦除且按异物统计。

采用标准清洁流程前后拍照。

检测算法建议

清洁前后差分 + 反光/低频色斑检测；对灰尘点、油膜、手印分别建类；输出是否建议清洁复检。

需控制样本标签，避免与异物混标。
