3. P0 验收主路径（最短闭环）
任务书硬交付只经本路径，不经 PLC / 在线 L1 / 近线工具层。
sequenceDiagram
  participant Cam as 采集/放图
  participant Raw as raw-data
  participant CLI as offline-detect CLI
  participant YOLO as yolo11s-seg
  participant AD as EfficientAD可选
  participant FS as 输出目录
  participant UI as detector-ui
  participant Human as 人工复核/盲测

  Cam->>Raw: 原图入库（版本化）
  Raw->>CLI: detect --input --output --model
  CLI->>YOLO: 必选推理
  CLI->>AD: 可选 anomaly
  YOLO-->>CLI: defects[]
  AD-->>CLI: anomaly 摘要
  CLI->>FS: result.json + overlay.jpg
  FS->>UI: npm run sync-data → jobs JSON
  UI->>Human: 框/列表/回放
  Human->>Raw: 确认样本回流训练集 7:2:1
