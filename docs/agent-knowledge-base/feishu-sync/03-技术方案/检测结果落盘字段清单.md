4. 请不要填（前端 mock / 评测用，不是模型输出）
这些是 detector-ui 演示指标用的，算法 JSON 里不要写：
gold_ng、pred_ng、outcome、match、件级 confirmed/rejected/relabelled
复核状态由人工在前端改；你落盘只出 pending。

5. 目录怎么放（交一份就按这个拷）
detect-output/
└── 20260821/                 # 跑模型的日期，YYYYMMDD
    └── P-20260821-001/       # 一件一目录
        ├── image.jpg         # 单面；多面改为 top.jpg / right.jpg …
        └── result.json
多面时：同一 piece_id 目录里 top.json + top.jpg，或每面仍用 result.json 但 surface / image_file 写对。前端靠 piece_id 合成一件。
最小 result.json（无缺陷 OK 件）：
{
  "schema_version": "1.0",
  "piece_id": "P-20260821-001",
  "batch_id": "B-01",
  "surface": "top",
  "image_file": "image.jpg",
  "image_size": [3200, 1920],
  "model_version": "yolo11s-seg-v0.3",
  "detected_at": "2026-08-21T10:00:00+08:00",
  "infer_ms": 180,
  "review_status": "pending",
  "defects": []
}
有缺陷时在 defects 里加框，bbox 用数组。完整带框示例见接口稿 v0.3 §4.5。
